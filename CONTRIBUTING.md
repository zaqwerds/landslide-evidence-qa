# Contributing

Bug reports, documentation improvements and code fixes are welcome. Include reproduction steps, Python and Neo4j versions, the displayed error and expected behavior.

Do not include restricted reports, API keys, database passwords, personal information or local runtime directories in issues, commits, screenshots or examples. Use fictional or otherwise authorized material.

Read the [README](README.md), work on a separate branch, and describe the reason for the change, affected web operations and checks performed. Keep parsing, graph construction, browsing and QA accessible from the web application. Paper-result reconstruction is a separate optional example, not an application dependency or an integrated comparison system.

Write comments and docstrings in English. Preserve prompt strings, database labels, report vocabulary and behavior unless a functional change is explicitly intended and tested.

Provide provenance and permission information for third-party ontologies, data or code. Do not submit material of unknown provenance or material that cannot be redistributed.
